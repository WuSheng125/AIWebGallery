GARGANTUA · 黑洞观测站
=======================

启动
----
在当前项目根目录执行：
  npm start
然后打开终端显示的本机网址，默认 http://127.0.0.1:8765 。
不需要 npm install，也不需要联网获取依赖。

独立使用本文件夹时：
  node serve.cjs

也可以用支持 WebGL 2 的桌面浏览器直接打开本文件夹中的 index.html。
所有脚本、样式、着色器均在本地，不依赖 CDN、图片资源或在线服务。
需要浏览器支持 WebGL 2 与硬件加速。关闭启动服务的终端即可停止本地服务。
如果 8765 端口已占用，可在 PowerShell 中设置 $env:PORT='8766' 后再启动。

操作
----
鼠标拖动：环绕观察，可从盘面上方或下方观察。
滚轮：缩放。触屏支持单指旋转、双指缩放。
方向键：旋转（焦点在观测画布时）。
Space：暂停 / 继续动画。R：重置视角。F：沉浸模式。
底部工具栏：暂停、自动环绕、重置视角、截图、沉浸模式。
截图按钮生成当前实际渲染画面的 PNG 预览，点击“下载 PNG”保存。
右侧控制台可滚动；手机尺寸通过顶部参数按钮打开。
控制台右上方重置按钮恢复参数、视角、时间和自动画质。

场景与参数
----------
卡冈图雅：金色吸积盘、弯曲的上拱弧与较暗的下弧。
蓝色巨环：冷色高温盘面，更高的观察角度。
暗夜视界：隐藏吸积盘，只看黑洞阴影与星空透镜。

黑洞尺度：相对视界半径，影响阴影、盘面尺度和弯曲区域。
自旋强度：影响盘面内缘、流动与 Doppler 对比的视觉参数。
引力透镜：控制光线曲率；设为 0 可比较未经偏折的平面吸积盘。
色温、外缘半径、辐射亮度、Doppler 增亮：调整吸积盘外观。
辉光强度：控制吸积盘的后期辉光。
星空密度：改变程序生成星点数量；设为 0 关闭星空。
时间流速：改变动画速度，0 冻结盘面流动。
渲染画质：自动 / 高画质 / 均衡 / 流畅。

实现与性能
----------
使用原生 JavaScript、CSS 和 WebGL 2 / GLSL，无第三方运行时依赖。
逐像素曲线光线积分，支持同一光线与薄吸积盘多次相交。
背景星空根据逃逸光线的世界方向生成，随引力透镜产生偏折。
程序化盘面纹理、方向相关增亮、分离式低分辨率辉光及色调映射。
画质档控制渲染像素预算和积分步数；自动模式根据帧率调整档位。
后台标签页跳过绘制，暂停后仅在镜头或参数改变时重绘。
窄屏扩大水平视野，避免完整吸积盘被裁掉。

模型范围
--------
这是受《星际穿越》卡冈图雅启发的电影风格实时近似。
采用 Schwarzschild 启发的曲线光线方程，未求解完整 Kerr 时空。
自旋、色温、透镜系数和二次盘面像亮度包含艺术化调整，
不能把本页面读数作为真实黑洞质量、温度或时空测量结果。

文件
----
index.html    界面与入口
style.css     响应式观测台样式
app.js        参数、相机交互、预设、帧循环、导出
renderer.js   WebGL 2 渲染管线与 GLSL 着色器
serve.cjs     可选的本地静态服务，仅绑定 127.0.0.1
