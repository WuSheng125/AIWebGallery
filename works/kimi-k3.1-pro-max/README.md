# Gargantua · 卡冈图雅黑洞

一个使用 **Three.js + TypeScript + GLSL** 构建的实时交互黑洞页面。视觉设计参考《星际穿越》中卡冈图雅的近侧视构图：纯黑事件视界阴影、炽亮吸积盘、被引力弯到黑洞上方和下方的盘像，以及扭曲的星空背景。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 操作

- **鼠标左键拖动 / 单指拖动**：围绕黑洞旋转视角。
- **滚轮 / 双指缩放**：靠近或远离黑洞。
- **右侧参数栏**：实时调整质量、引力透镜、吸积盘、多普勒束流、星空和后期效果。
- **预设**：一键切换卡冈图雅、暗红余烬和蓝色高盖三种形态。
- **保存画面**：将不包含 UI 的当前画布导出为 PNG。

## 渲染原理

页面不是播放视频，也不是用一张黑洞贴图旋转。每个像素都会从虚拟相机发出一条光线，用 Schwarzschild 几何下的近似零测地线方程积分：

```text
d²x/dλ² = -3/2 · Rs · |x × v|² · x / |x|⁵
```

光线经过赤道面时检测吸积盘交点，因此盘的背面、上方和下方透镜像自然共享相同光路。未落入事件视界的光线最终采样程序化星空，让星点随视角和质量发生引力偏折。吸积盘还包含径向温度、湍流条纹、较差自转、多普勒增亮和近似引力红移。

> 本项目以实时视觉表现为目标，采用 Schwarzschild 黑洞近似和艺术化辐射参数，并非完整的 Kerr 黑洞或专业辐射转移模拟。侧栏的“质量”以场景中的 Schwarzschild 半径为单位。

## 性能

- 单个全屏三角形完成光线积分，没有大量网格或纹理下载。
- 自适应步长与低 / 中 / 高三个档位同时控制积分精度、像素密度和像素总量。
- 半浮点 HDR 渲染、UnrealBloom、ACES 色调映射；Bloom 为零时跳过整个光晕阶段。
- 竖屏自动扩大视场并限制移动端像素密度，兼顾完整构图与性能。
- 页面不可见时停止更新动画时间。
- 所有星空和盘面细节程序化生成；安装依赖后无需外部图片、字体或 CDN。

如果设备帧率较低，先把画质切为“低”，再降低 Bloom 或盘面密度。集成显卡建议使用 1080p 或更低窗口分辨率。

## 验证

```bash
# 严格类型检查与生产构建
npm run build

# 保持开发服务器运行，在另一个终端执行真实浏览器回归
node scripts/verify-browser.mjs
```

浏览器脚本无需额外依赖，会使用本机 Edge 或 Chrome 检查 WebGL、鼠标旋转、参数与预设、画质像素比、帮助弹窗、PNG 下载及移动端布局，并把验证截图写入 `artifacts/`。可用 `APP_URL`、`CDP_PORT` 和 `BROWSER_PATH` 环境变量覆盖默认测试配置。

## 目录

```text
src/
  shaders/blackHole.frag   # 光线弯曲、吸积盘和星空
  shaders/fullscreen.vert  # 全屏三角形
  experience.ts            # Three.js 渲染、后期、相机与性能管理
  ui.ts                    # 参数面板、预设和界面状态
  main.ts                  # 应用组装与截图等操作
  style.css                # 响应式视觉样式
  types.ts                 # 参数类型和预设
```
