关于这个黑洞

它是怎么画出来的

画面不是贴图或后期特效，而是逐像素求解光线在弯曲时空里的真实路径：每一条光线都按史瓦西时空的零测地线方程积分， d²r/dλ² = −(3/2)·rs·h²·r/r⁵（h 为守恒角动量）。光线被引力弯折后继续飞行， 于是自然产生了爱因斯坦环、光子环，以及《星际穿越》里最标志性的画面——吸积盘的远侧被弯折到黑洞上方、近侧被弯折到下方，形成包裹住视界的那道"光之冠"。

吸积盘

  • 极薄几何盘位于赤道面，半径位于 ISCO（最内稳定圆轨道）与外缘之间。
  • 温度按 Shakura–Sunyaev 薄盘 T ∝ r−3/4 分布，再经黑体色温映射到颜色：内缘炽白，外缘转为琥珀金——正是电影里那种温暖的色调。
  • differential（开普勒）剪切带动程序化湍流随时间演化，内圈转得比外圈快。
  • 相对论多普勒集束使靠近观察者一侧变亮偏蓝、远离侧变暗偏红；强度为 g⁴。电影里诺兰为了让画面左右对称，特意把它关掉了——默认参数保留了很轻微的一点点。
  • 引力红移 √(1−rs/r) 让靠近视界的辐射变暗变红。

天空

背景星场与星云是按方向程序化生成的，并且同样要走过那条弯曲的光线，所以黑洞周围的星空会被拉伸、复制成环——这是引力透镜对背景的真实作用。

单位

全场采用几何单位 G = c = 1，并令史瓦西半径 rs = 1（即 M = 0.5）。所有距离滑块的单位都是 rs；史瓦西黑洞的 ISCO 正好在 3 rs 处。

关于自旋

透镜与红移采用严格史瓦西解（无自旋）。自旋滑块按克尔度规给出正确的 ISCO 半径并驱动"近似参考系拖曳"与多普勒不对称，属于艺术近似而非严格克尔测地线。真实卡冈图雅被设定为 a* ≈ 0.999 的近极端克尔黑洞。

性能

原生 WebGL2，零第三方依赖。HDR 浮点累积缓冲 + 渐进式多重采样（相机静止时逐帧累加做抗锯齿）+ 可分离高斯泛光 + ACES 色调映射。卡顿时请下调「渲染分辨率」与「光线步数」，或把画质预设调低。
