# GARGANTUA · 卡冈图雅

一个基于 WebGL2 的交互式黑洞实时渲染页面，外观参考电影《星际穿越》中的超大质量黑洞「卡冈图雅」：金色吸积盘、圆形黑色阴影、光子环、被引力透镜弯折后在黑洞上方/下方形成的次级盘像，以及被扭曲成弧线的背景星空。

**零第三方运行时依赖**——不加载 CDN、不需要构建、不需要 npm 安装，纯原生 WebGL2 + GLSL ES 3.00。

---

## 运行

直接用现代浏览器打开：

```
hy4-high/index.html
```

已验证在 `file://` 协议下可正常工作（Edge / Chromium）。如果希望用本地服务器：

```bash
cd hy4-high
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

要求：支持 **WebGL2** 的浏览器（Chrome / Edge / Firefox 近几年的版本），建议开启硬件加速。

## 技术实现

### 1. 引力透镜：Schwarzschild 零测地线积分

每个像素从相机发射一条光线，在笛卡尔坐标下按下面方程逐步积分：

```
d²r⃗/dλ² = -(3/2) · r_s · h² · r⃗ / |r|⁵ ,   h = |r⃗ × v⃗| = b (碰撞参数，守恒)
```

该式由轨道方程 `d²u/dφ² + u = 3M u²` 推出，能正确复现：

- 弱场偏折角 `Δφ = 2 r_s / b`
- 光子球 `r = 1.5 r_s`
- 黑洞阴影临界碰撞参数 `b_crit = 3√3 M = 2.598 r_s`

采用半隐式欧拉 + 自适应步长 `dt ∝ r`，并对「已经远离且向外传播」的光线提前退出；进入光子球即判定被捕获，保证阴影是纯黑且节省算力。

### 2. 吸积盘

- 光线每次穿越赤道面 `y = 0` 时插值求交点，若半径落在 `[r_in, r_out]` 内就累加一次盘面辐射。绕黑洞旋转多圈的光线会多次穿越赤道面，自然产生黑洞上方/下方的**透镜次级像**和光子环。
- 辐射颜色按径向温度梯度从白热内缘过渡到橙红外缘，可用「色温」整体偏移到蓝白。
- 纹理由**域扭曲 fbm 噪声**生成，并按开普勒角速度 `ω ∝ r^-1.5` 差动旋转，形成螺旋细丝。
- **相对论多普勒集束**：`D = 1/(1 - β·μ)`，强度 `∝ D^(1+2.5·k)`，同时做蓝移/红移着色，使朝向观察者的一侧明显更亮。

### 3. 星空与后期

- 程序化恒星（三层不同尺度/密度）+ 低频星云 + 一条银河带；用**弯曲后的光线方向**采样，因此恒星会被拉成爱因斯坦弧。
- 渲染管线共 6 个 pass：HDR 场景 → 亮部提取+横向模糊 → 纵向模糊 → 二次降采样横向模糊 → 纵向模糊 → 合成。
- HDR 使用 `RGBA16F`（`EXT_color_buffer_float`），不可用时自动回退 `RGBA8`。
- 合成阶段：色散 → 双级 Bloom → ACES 电影色调映射 → 暗角 → 颗粒 → sRGB gamma。

### 4. 性能

- 单个全屏三角形，无几何体、无纹理上传。
- 自适应步长 + 逃逸提前退出 + 光子球提前判定，大幅减少无效积分。
- 4 档质量（110 / 150…360 步，0.55× ~ 1.0× 分辨率，DPR 上限 1.0~1.5）。
- 自适应分辨率：帧率持续偏低时自动降低内部渲染分辨率，回升后再恢复。
- Bloom 在 1/2、1/4 分辨率上做可分离高斯模糊，开销很小。

## 文件结构

```
hy4-high/
├── index.html          # 页面结构、HUD、侧边栏容器
├── css/style.css       # 界面样式（暗色 / 琥珀色遥测风格）
└── js/
    ├── shaders.js      # 全部 GLSL：黑洞测地线积分、Bloom、合成
    ├── renderer.js     # WebGL2 上下文、FBO、6-pass 渲染管线
    └── main.js         # 参数状态、UI 生成、相机、交互、主循环
```

> 所有长度以史瓦西半径 `r_s` 为单位；默认取 `r_s = 1`。
