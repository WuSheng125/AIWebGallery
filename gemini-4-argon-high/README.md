# GARGANTUA 卡冈图雅 — 《星际穿越》广义相对论黑洞交互式观测台

基于 **Three.js + WebGL2 广义相对论零测地线光线步进（Null Geodesic Raymarching）** 构建的电影《星际穿越》（*Interstellar*）卡冈图雅（Gargantua）黑洞图形化实时预览网页。

---

## 核心特性

1. **广义相对论克尔/史瓦西度规光线步进（Geodesic Raymarching）**
   - 实时积分弯曲时空中的光子运动方程（包含史瓦西引力偏折项与克尔自旋参考系拖拽 Lense-Thirring 效应）。
   - 真实呈现**事件视界绝对黑影（Event Horizon Shadow）**、**光子球临界亮环（Photon Ring）**以及吸积盘背面经强引力透镜折射形成的**上下双光弧（Gravitational Lensing Arches）**。

2. **《星际穿越》卡冈图雅风格相对论吸积盘**
   - 采用赤道面解析求交（消除光线步进摩尔纹）结合三维体积等离子体云渲染。
   - 内置开普勒差异旋转螺旋湍流纹理、诺维科夫-索恩（Novikov-Thorne）径向温度分布及**相对论多普勒集束效应（Relativistic Doppler Beaming）**——朝向观测者旋转的一侧蓝移增亮，背离观测者的一侧红移变暗。
   - 支持切换 5 种辐射光谱色彩模型（卡冈图雅电影暖金、普朗克物理黑体辐射 Kelvin、高能类星体蓝紫、M87* 深红余烬、磁星极光青紫）及南北极相对论磁流体喷流。

3. **无畸变深空背景恒星场与引力透镜爱因斯坦环**
   - 基于立方体天球投影的多层物理色温恒星场与银河系星云尘埃带。
   - 背景星光经过黑洞引力场时发生真实偏折与透镜通量放大，在临界冲击参数附近形成**爱因斯坦环（Einstein Ring）**。

4. **全自由度鼠标相机控制与实时天体物理参数侧边栏**
   - **鼠标左键拖拽**：360° 球面环绕旋转观察。
   - **鼠标右键 / Shift + 左键拖拽**：电影镜头横滚角（Dutch Roll）旋转。
   - **鼠标滚轮**：平滑对数缩放观测距离（支持抵近至光子球附近）。
   - **实时参数调节与天体物理遥测**：根据 Барdeen-Press-Teukolsky (1972) 克尔度规公式实时解算史瓦西半径 $R_s$、最内稳定圆轨道 $R_{\text{ISCO}}$、光子球半径 $R_{\text{ph}}$、内缘相对论流速 $v/c$ 及引力时间膨胀率。

## 运行方式

### 方式一：直接双击打开（零配置）
项目已内置本地 `vendor/three.min.js`，无需联网或构建步骤，直接在浏览器中双击打开 [`index.html`](./index.html) 即可流畅运行。

### 方式二：通过本地 HTTP 服务运行
```bash
node serve.mjs
```
然后访问 `http://127.0.0.1:8090`。
