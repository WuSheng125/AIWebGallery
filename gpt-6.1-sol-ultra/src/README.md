# GARGANTUA · 黑洞观测台

WebGL 2 实时黑洞预览：电影风格的暖金色吸积盘、弯曲光线、上下透镜盘影像、黑洞阴影、程序化星空、盘面差速旋转、多普勒明暗及色温变化和多尺度光晕。界面和错误提示均为中文。

## 运行

无需安装任何第三方依赖。安装 Node.js 18 或以上版本后，在项目目录运行：

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。服务器只监听本机回环地址。

如果端口已被占用，PowerShell 中可指定其他端口：

```powershell
$env:PORT = 5174
npm run dev
```

生成可直接双击、完全离线运行的单文件网页：

```sh
npm run build
```

生成的 `outputs/gargantua.html` 不需要服务器和外部 CDN。浏览器需要支持 WebGL 2，并启用硬件加速。建议在普通浏览器中打开；应用内预览窗口可能限制全屏和下载。

## 可调参数

- 黑洞尺度：改变事件视界、阴影和盘面在固定观察距离下的表观大小。
- 透镜强度：0 关闭光线弯曲；1 为基础轨道模型；更高值用于加强视觉效果。
- 外缘半径：以基础事件视界半径 Rₛ 为单位改变盘面尺寸。
- 盘面色温：暖橙到蓝白的色彩风格，非经过校准的真实气体温度。
- 辐射亮度、多普勒效应：改变盘面亮度及两侧明暗和色彩差异。
- 盘面厚度、流速：改变有限厚度发光层和纹理流动。
- 星空亮度、光晕强度：改变星光和盘面辉光。
- 画质：自适应、高画质、均衡、流畅。
- 视角：电影低仰角、俯视、接近侧视。

## 渲染与性能

原生 WebGL 2 / GLSL ES 3.00，三个全屏渲染通道，不依赖 Three.js。第一通道使用 Velocity Verlet 积分近似 Schwarzschild 光子空间轨道，盘面穿越产生前景盘与远侧镜像，逃逸方向用于采样星空。有限厚度发光层使近侧视时仍有盘面可见。第二通道以四分之一宽高提取并扩散高亮；最后合成光晕、暗角与轻微静态颗粒。

画布显示 DPR 上限为 1.5；昂贵的光线积分分辨率独立限制在约 150 万像素。自适应模式优先使用 GPU 计时扩展，无法获取时根据帧间隔调整分辨率。使用 168 / 208 / 256 的积分预算；切换画质可改变预算。后台标签页停止动画，暂停并停止相机运动后不再持续渲染。窗口尺寸改变会重绘，避免暂停后黑屏。

这是电影风格的实时近似，采用非旋转模型，未完整求解 Kerr 自旋时空，也不提供科研级温度、相对论时间膨胀或精确光束抗锯齿。透镜强度可独立修改，因此非 1 的设置主要用于视觉探索。电影风格参考 [James 等人的原始论文](https://arxiv.org/abs/1502.03808)，空间轨道积分参考 [Bruneton 的黑洞渲染论文](https://ebruneton.github.io/black_hole_shader/paper.pdf)。实现代码为本项目编写。

## 文件

- `index.html` / `styles.css`：界面与响应式布局。
- `app.js`：状态、参数、相机输入和可选浏览器 WebMCP 控制。
- `renderer.js`：WebGL 资源、相机、分辨率、自适应与截图。
- `shaders.js`：光线积分、吸积盘、透镜星空与光晕。
- `server.mjs`：零依赖本地静态服务器，只提供公共网页文件。
- `build.mjs`：生成单文件离线网页。

语法检查：`npm run check`。
